# Icon sources

The transparent Tailwind CSS, React, Next.js, Chrome, VisX, Mantine,
Headless UI, Radix UI, and TanStack marks come from
[Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). The React
Aria mark uses Adobe's logo from Simple Icons 11.15.0 (CC0).
Brand marks remain subject to their owners' trademark guidelines.

The Gmail contact icon preserves the original multicolor logo from
`gmail.jpg`; its white JPEG background is removed in the transparent PNG.

The Next.js mark omits the enclosing disk so it has no circular backplate.

The KaTeX hummingbird is a simplified vector interpretation of the existing
site icon. Physics and Mathematics are custom SVG illustrations. These assets
have transparent backgrounds; the experiment icon component colors monochrome
and science icons through the site's theme tokens.

The GitHub marks in the header and contact card use the installed
`@radix-ui/react-icons` package.
