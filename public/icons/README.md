# Icon sources

The transparent Tailwind CSS, React, Next.js, Chrome, VisX, Mantine,
Headless UI, Radix UI, and TanStack marks come from
[Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). The React
Aria mark uses Adobe's logo from Simple Icons 11.15.0 (CC0).
Brand marks remain subject to their owners' trademark guidelines.

The Gmail contact icon preserves the original multicolor logo from
`gmail.jpg`; its white JPEG background is removed in the transparent PNG.

The Next.js mark omits the enclosing disk so it has no circular backplate.

The KaTeX hummingbird is a simplified vector interpretation of the existing
site icon. Physics, Mathematics, Browser, and User Interface are custom SVG
illustrations.
These assets have transparent backgrounds; the lab icon component colors
monochrome and domain icons through the site's theme tokens. They share a 24px
canvas and rounded 1.5px strokes. Mathematics uses a flowing infinity mark,
Browser a rounded window, and User Interface slider controls. Colors remain
`violet-500` for Mathematics, `teal-600` for Browser, `rose-500` for User Interface,
and `green-600` for Physics.

The GitHub marks in the header and contact card use the shared local
`GitHubIcon` SVG component, based on the Simple Icons GitHub mark (CC0).
Archived lab marks are retained only for the discontinued history cards.
